# 团队知识库

Markdown 是事实源。检索数据库可以重建；AI 提出的知识经用户确认后保存。

团队成员查询知识并提出候选，由团队约定的知识维护者审核入库。共享范围和审核职责由团队明确；个人使用时由本人负责。

| 目录 | 用途 |
|---|---|
| 00_资源库 | 保留原始证据，不覆盖原件 |
| 01_主题Wiki | 方法、问题案例、解决方案、踩坑经验 |
| 02_项目库 | 项目背景、约束和决策 |
| 03_输出库 | 正式方案、复盘与成果 |
| 04_系统维护 | 模板、反馈、进化提案与使用说明 |

从[收件箱](收件箱.md)记录线索，按[知识录入说明](04_系统维护/知识录入说明.md)形成可复用知识。模板位于 `04_系统维护/模板`，不进入正式检索。
